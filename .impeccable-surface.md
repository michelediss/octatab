## Scope

New Tab launchpad; visitor mode: Operate.

## Audience and job

Brave Desktop users need to open a small set of chosen sites quickly and maintain that set locally.

## Action and constraints

Primary action is adding a site. Site links open natively. No backend, remote assets, extra permissions, or dashboard widgets.

## Direction

Firefox-like New Tab surface: centered 8-column field, graphite or near-white canvas, soft icon squares, centered labels, and one lower-right pencil control. No logo, masthead, count, or visible dashboard chrome.

## Memorable moment

The first saved site becomes a physical-looking “pin” in the field, while the empty state gives the user a clear first pin to place.

## Open decisions

None for MVP.
